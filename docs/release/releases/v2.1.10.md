Status: review
Date: 2026-10-13

The maintainer selected **2.1.10** for release. `VERSION`, `pyproject.toml`
and active version documents agree. This preparation commits the changes;
tagging, pushing and publication remain separate steps.

## Included changes

- Native forest multi-interval CSV sources/mappings, intervals-only rows,
  box/scatter coexistence and literal CSV numeric annotations.
- Shared explicit x ticks independent of grid divisions; floating-point grid
  deduplication and actual short-tick/label regression checks.
- Explicit MathText and STIX/DejaVu formula fonts, independent legend/cut
  selectors, supplied header notes, preserved paragraphs/formulas and actual
  font/glyph/annotation bounds. Balanced multi-interval example row geometry.
- Unified CLI/export provenance, correct TTC weight/slant and font-size
  measurement; bounded metadata fallback and observable export/I/O failures.
- Packaged AI README, schema/man/examples updates, release/resource gates,
  source-distribution examples and Linux/macOS CI coverage.

The detailed design review and 44-figure/CSV verification with the preceding
local candidate are recorded in [2.1.9 closure](v2.1.9.md). No statistics,
physics cuts, training results, research datasets or existing figures change.
Existing forest YAML requires no interface migration.
