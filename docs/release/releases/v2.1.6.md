# JarvisPLOT 2.1.6 release candidate

Status: review

Version is set to `2.1.6` in `VERSION` and `pyproject.toml`. This note records
local release preparation; publication/tagging is a separate step.

## Changes

- Layers declare `legend: {object, label, role}`. Components of the same object
  assemble into one native legend item on their axes. A single component can
  omit `role`; colors, lines, markers, error bars and caps come from real artists.
- Per-axes legend settings select a JSON card and control order, columns,
  position, fonts and spacing. Installed cards: default, compact, paper and
  presentation. Custom cards and YAML template overrides are supported.
- `jplot man legend --json` includes the live card catalog. Validation checks
  role sets, duplicate roles, inconsistent labels, ambiguous formats and order.
- Recent PDF1D/CDF1D reconstruction supports weighted samples, repeat statistics,
  adaptive empirical anchors and monotone interpolation. Grid size controls
  evaluation, not fitting.

## Unified legend contract (breaking change)

`layer.legend: {object, label, role}` is the sole item declaration. Axes
`entries`, `preset`, `handles`, `labels`, `axes` and figure-level legend are
rejected. Artist/series labels do not create items. An enabled legend requires
at least one declared object. Disabled legends still validate their declarations.
Explicit axes `legend: false` / `enabled: false` disables drawing.
Declared multi-series layers must be split into unambiguous components;
no first-handle guessing or swallowed render errors remain. Doctor exposes
canonical object/label/role membership. See `docs/specs/LEGEND.md` for migration.

## Review fixes

- Keep the middle stacked line aligned with native line keys when increasing
  `handleheight` (including the paper/presentation defaults).
- Report malformed style tokens as validation diagnostics instead of crashing
  while reading legend defaults.
- Bind components exclusively by layer position internally; remove the named
  reverse-reference registry so layer names cannot collide with internal keys.
